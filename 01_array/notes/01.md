# Array Complexity in Python

This section explains the time complexity of common operations on Python's `array.array`.

## What is Time Complexity?

Time complexity describes how the execution time of an operation grows as the number of elements (`n`) increases.

Common complexities:

- **O(1)** — Constant time
- **O(n)** — Linear time
- **O(k)** — Depends on the number of elements being added or processed

---

## Array Operations Complexity

| Operation | Complexity | Description |
|---|---:|---|
| `arr[i]` | **O(1)** | Access an element by index |
| `append(x)` | **O(1) amortized** | Add an element to the end |
| `extend(iterable)` | **O(k)** | Add `k` elements |
| `insert(i, x)` | **O(n)** | Insert an element at a specific position |
| `remove(x)` | **O(n)** | Find and remove an element by value |
| `pop()` | **O(1)** | Remove the last element |
| `pop(i)` | **O(n)** | Remove an element at a specific index |
| `index(x)` | **O(n)** | Find the index of a value |
| `count(x)` | **O(n)** | Count occurrences of a value |
| `reverse()` | **O(n)** | Reverse the array |
| `tolist()` | **O(n)** | Convert the array to a list |
| `tobytes()` | **O(n)** | Convert the array to bytes |
| `fromlist(L)` | **O(k)** | Add `k` elements from a list |

> **Note:** `n` is the number of elements already in the array, while `k` is the number of elements being added or processed.

---

## 1. Access by Index — O(1)

Accessing an element using its index takes constant time.

```python
letters = array('w', ['a', 'b', 'c', 'd', 'e'])

print(letters[3])
```

Output:

```text
d
```

The array can directly access the requested position without checking every element.

```text
Index:   0   1   2   3   4
Value:   a   b   c   d   e
                     ↑
                  letters[3]
```

**Complexity: O(1)**

---

## 2. Append — O(1) Amortized

`append()` adds an element to the end of the array.

```python
letters.append('f')
```

Before:

```text
a b c d e
```

After:

```text
a b c d e f
          ↑
        added
```

Because the element is added at the end, it is usually a constant-time operation.

**Complexity: O(1) amortized**

> "Amortized" means that although an occasional resize can take longer, the average cost over many `append()` operations is O(1).

---

## 3. Extend — O(k)

`extend()` adds multiple elements.

```python
letters.extend(['f', 'g', 'h'])
```

If `k = 3`, three elements need to be added.

```text
Before:
a b c d e

After:
a b c d e f g h
          └───┘
          3 elements
```

**Complexity: O(k)**

---

## 4. Insert — O(n)

`insert()` adds an element at a specific position.

```python
letters.insert(0, 'x')
```

If the element is inserted at the beginning, existing elements need to be shifted.

```text
Before:
a b c d e

Insert x at index 0:

x a b c d e
  → → → → →
```

The more elements the array has, the more elements may need to be moved.

**Complexity: O(n)**

---

## 5. Remove — O(n)

`remove()` removes an element by its value.

```python
letters.remove('c')
```

Python may need to search through the array until it finds `'c'`.

```text
a → b → c
        ↑
      found
```

After finding the element, other elements may need to be shifted.

**Complexity: O(n)**

---

## 6. Pop — O(1) or O(n)

`pop()` removes an element and returns it.

### Pop the Last Element

```python
value = letters.pop()
```

Example:

```text
Before:
a b c d e
        ↑
      remove

After:
a b c d
```

No shifting of other elements is necessary.

**Complexity: O(1)**

### Pop by Index

```python
value = letters.pop(1)
```

If an element in the middle is removed, the following elements need to be shifted.

```text
Before:
a b c d e
  ↑
remove

After:
a c d e
  ← ← ←
```

**Complexity: O(n)**

---

## 7. Index — O(n)

`index()` searches for the position of a value.

```python
position = letters.index('d')
```

Python may need to check the elements one by one.

```text
a → b → c → d
            ↑
          found
```

In the worst case, it may have to check all `n` elements.

**Complexity: O(n)**

---

## 8. Count — O(n)

`count()` counts how many times a value appears.

```python
total = letters.count('a')
```

Python needs to check every element because the value could appear anywhere.

```text
a → b → a → c → a
↑       ↑       ↑
  count all occurrences
```

**Complexity: O(n)**

---

## 9. Reverse — O(n)

`reverse()` reverses the order of the elements.

```python
letters.reverse()
```

Example:

```text
Before:
a b c d e

After:
e d c b a
```

The operation processes the elements in the array.

**Complexity: O(n)**

---

## 10. To List — O(n)

`tolist()` creates a list containing the elements of the array.

```python
result = letters.tolist()
```

Example:

```python
letters = array('w', ['a', 'b', 'c'])

result = letters.tolist()

print(result)
```

Output:

```text
['a', 'b', 'c']
```

All `n` elements need to be copied into the new list.

**Complexity: O(n)**

---

## 11. To Bytes — O(n)

`tobytes()` converts the array into a bytes object.

```python
result = letters.tobytes()
```

The operation processes the elements to create the bytes representation.

**Complexity: O(n)**

---

## 12. From List — O(k)

`fromlist()` adds all elements from a list to the array.

```python
letters.fromlist(['x', 'y', 'z'])
```

If the list contains `k` elements, those `k` elements need to be added.

**Complexity: O(k)**

---

# Summary

## O(1)

- Access by index: `arr[i]`
- `append()`
- `pop()` from the end

## O(n)

- `insert()`
- `remove()`
- `pop(i)`
- `index()`
- `count()`
- `reverse()`
- `tolist()`
- `tobytes()`

## O(k)

- `extend()`
- `fromlist()`

---

## Quick Rule

> **Access by index → O(1)**  
> **Add/remove at the end → O(1)**  
> **Insert/remove in the middle → O(n)**  
> **Search → O(n)**  
> **Process all elements → O(n)**  
> **Add `k` elements → O(k)**
